# DOKKIITECH Portfolio

Clean portfolio site built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Structure

- `/` Home
- `/projects` Projects
- `/contact` Contact

`/products` is kept as a backward-compatible redirect to `/projects`.

## Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- pnpm

## Run Locally

```bash
git clone https://github.com/dokkiitech/portfolio.git
cd portfolio
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Scripts

```bash
pnpm dev    # Start local dev server
pnpm build  # Production build
pnpm lint   # Lint checks
pnpm start  # Start production server (port 3006)
```
